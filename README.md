# Employee Attrition Analysis Dashboard

An interactive data analytics project focused on exploring employee attrition patterns and understanding the factors that influence employee turnover.

## Project Overview

Employee attrition is an important challenge for organizations. This project aims to analyze employee-related data and present meaningful insights through an interactive dashboard.

The application provides a way to explore employee information, examine attrition trends, and understand patterns within the dataset.

## Key Features

- Interactive Employee Attrition Dashboard
- Employee data exploration and analysis
- Data visualization and insights
- Employee information management
- Analysis of employee turnover patterns

## Technologies Used

- **Python** – Backend development and data processing
- **HTML** – Webpage structure
- **CSS** – Styling and layout
- **JavaScript** – Frontend interactivity
- **CSV** – Dataset storage

## Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/Bhoomi-ch/Employee_Attrition_Project_zip.git
```

**2. Open the project folder**

```bash
cd Employee_Attrition_Project_zip
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
python app.py
```

Open the local URL displayed in your terminal to access the dashboard.

The project uses a CSV-based employee dataset for exploring attrition patterns and employee-related information.
